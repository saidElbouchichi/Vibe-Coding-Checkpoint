# Foundations of AI-Powered Vibe Coding — Checkpoint (GOMYCODE)

Page d'introduction personnelle créée avec l'aide d'outils d'IA, présentant :
- mon profil (ingénieur en automatisme / informatique industrielle en reconversion vers le développement frontend) ;
- mes passions (automatisme, développement web, intelligence artificielle, engagement associatif) ;
- mon objectif en tant que développeur frontend.

## Fichiers
- `index.html` — structure de la page
- `style.css` — style (palette sombre/ambre)
- `script.js` — petite animation d'apparition au défilement

Ouvrir `index.html` dans le navigateur pour voir le résultat.
